Opensource Clipping

Turn long videos into short vertical clips.

Give it a podcast, interview or lecture. It picks the strongest moments, crops each one around the speaker’s face, and adds subtitles and music.

What it does

  • Reads the transcript and asks Gemini to choose the best moments.
  • Follows the speaker’s face so the vertical crop stays centered.
  • Burns in word-by-word subtitles and mixes in background music.
  • Writes a title, description and hashtags for each clip.

How to use it

Studio is the web front end. It connects to a server that you run yourself, for example in a free Kaggle or Colab notebook with a GPU. Open Studio, choose Connect, and paste the server address.

You can also run it on your own computer from the command line. The setup steps are in the repository.

Use your own videos

Only clip videos you own or have permission to reuse.
